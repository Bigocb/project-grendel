# Project Grendel

An RPG project focused on deep progression, build diversity, and gear evolution.

## Core Pillars
- **Progression:** Numbers must go up. Clear, rewarding growth loops.
- **Build Diversity:** Viable and interesting playstyles (Melee, Mage, Bard, etc.).
- **Gear Evolution:** Upgrading, blacksmithing, and trading systems.
- **Build Experimentation:** Testing diverse builds against challenging enemies.

## Documentation Structure
- `/docs/brainstorming`: Early ideas, chat logs, and concept sketches.
- `/docs/spec`: Formal technical specifications and game design documents.
- `/docs/protocol`: Rules of engagement, data formats, and API definitions.
- `/docs/concept`: High-level vision and thematic goals.
